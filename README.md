# Crunchyroll Power Up

Una extensión de navegador que mejora la experiencia de Crunchyroll con funciones avanzadas.

## Características

- **Mini Player**: Reproduce videos en una ventana flotante
- **Botones de salto**: Navegación rápida entre episodios
- **Control PiP**: Picture-in-Picture mejorado
- **Filtros de calendario**: Organiza mejor tu contenido
- **Botones de tamaño de pantalla**: Control de resolución
- **Fechas de emisión**: Información de episodios

## Instalación

1. Descarga o clona este repositorio
2. Abre Chrome/Edge y ve a `chrome://extensions/`
3. Activa el "Modo de desarrollador"
4. Haz clic en "Cargar extensión sin empaquetar"
5. Selecciona la carpeta de la extensión

## Versión

**v1.6.32** - Versión actual con todas las funciones implementadas

## Permisos

La extensión requiere permisos para:
- Almacenamiento local
- Acceso a pestañas activas
- Acceso a dominios de Crunchyroll
- Integración con AniList GraphQL

## Soporte
